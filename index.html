desktop app · open source · new

UmaStudio

A pose and render tool for Uma Musume. It loads characters straight from your installed game: pick a pose and an expression, give her a prop and a background, then save a PNG, GIF, video or a .glb model.

  • 90+ Umas and their chibis, 4,000+ poses, 500+ hand props
  • Uses the game's own hair and cloth physics
  • Custom pictures on props, e.g. your tournament's badge on a box
  • Python
  • three.js
  • WebView2
umastudio.byharuki.dev ↗ GitHub ↗

web app · private, for tournament staff

AimCup Pool Planner

Replaces the mappool spreadsheets. Mappers claim slots, upload their .osz and tick off a checklist; poolers, QA and playtesters each get their own view of the pool. Shown here with demo data.

  • Pool layout per stage, map claims and holds
  • .osz uploads are parsed: BPM, CS, AR, OD come from the file
  • QA board, playtesting, pooling suggestions, exports
  • Next.js
  • PostgreSQL
  • osu! OAuth
  • osu! API v2

web app · live

osu! tournament stats

Feed a stage its MP links and it pulls every score, lets an admin review them, and publishes the stats: per map, per player and per team, plus a scouting view for the next match.

  • Mappool pages with top plays and pick / ban rates
  • Seeding by zipf, ranked by accuracy or score
  • Head-to-head scouting between any two teams
  • Next.js
  • PostgreSQL
  • osu! API v2
stats.byharuki.dev ↗

discord bot + dashboard · live

UmaCore

Club management for Uma Musume. The bot tracks every member's daily and monthly fan quota and posts reports; the dashboard lets club leaders and members check it without Discord.

  • Used by 370+ clubs and 9,000+ members
  • Course maps showing where each skill fires
  • Verified Discord app
  • Python
  • discord.py
  • Next.js
  • PostgreSQL
